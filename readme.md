Tabnine

A installer directement dans l'IDE. N'est pas accessible depuis le browser.

Décrit comme un  "coding assistant" qui peut aider notamment pour l'autocomplétion ou d'autres tâches liées au développement d'applications.

Les outils peuvent être customisés pour les besoin de l'équipe utilisant Tabnine.

Contient un Code Explorer permettant de parcourir un projet qui nous est inconnu et permettre de le prendre en main plus rapidement.

Tabnine provides inline code completions as you continue coding, offering real-time, context-aware suggestions that seamlessly blend with your coding style.

You can often generate whole code sections just by hitting Tab and Enter
